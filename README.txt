FuDOrg — Organic Dietary Food Finder
====================================

PAGES
1. index.html          Home page
2. explore.html        Searchable food/ingredient explorer
3. dietary-finder.html Preference-based ingredient finder
4. about.html          About FuDOrg / story
Shared header and footer appear throughout.

TECHNOLOGY
- HTML5
- CSS3 (responsive layouts and rustic farm-to-table palette)
- Vanilla JavaScript
- Pacifico cursive font for the brand and expressive headings
- Nunito Sans for readable body copy
- Sample ingredient data is embedded in assets/app.js

RUN
Extract the ZIP and open index.html in a modern browser.
For best results, use a local static server such as VS Code Live Server.
Internet is required for Google Fonts and remote Unsplash images.

IMPORTANT
This is a front-end prototype. Search and dietary filtering work against
sample data only. Newsletter is a demonstration and does not send emails.
No backend, user accounts, persistent preferences, medical advice, or
verified nutrition database is included. Check all nutrition and allergen
details against reliable product-specific sources before production use.
Some remote images may be unavailable or change; replace with licensed
local images before public launch.
